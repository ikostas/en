Happy Hacking New Year, 2027 Edition

  • 24 November 2026
  • #linux,
  • #productivity,
  • #dev

Inspiration

Once I was just looking for something on my computer and saw this:

It's a documentation browser, and it looks outdated, because it's written in Perl and old Tk, but it accomplishes a lot:

  • It can open documentation in pdf, dvi, ps, txt and html formats
  • It has a search
  • It can print
  • It has games!
  • It has Settings and About sections

The authors were probably concerned about simplicity, size, speed and some other stuff which modern developers do not remember how to spell. And I thought: it's a perfect candidate to do something, as the content (still useful, by the way) is there. Maybe someone even wrote something more modern, but it will not stop us!

The ways

According to what I've learned and bearing portability in mind, there are the following paths to improve the user experience and worsen everything else, he-he-he:

  • Zenity, if you prefer pure shell scripting – and it's probably a good path here, because you're going to call external programs a lot
  • Python + Tk, if you prefer Python (which is not a bad idea per se, but do not forget the linter)
  • Go + Tk, which is the closest to the original idea you can get and even one step further (as Go is a lot better than Perl)
  • An HTML page with a search or a number of HTML pages, which you'll probably want to generate programmatically
  • .net with avalonia, just don't think about the app size so much
  • A web app would probably be overkill, but nevertheless: a web app
  • And, new in our list: a local LLM with a vector database to ask questions about the docs and get the answers

Conclusion

Programming by hand and not generating code seems counter-intuitive, but I'd argue that it's still one of the most satisfying hobbies, especially when you do understand what each line of code and each function does and why it's written this way. That doesn't mean you can't ask for clarifications, examples, directions, but don't rob yourself of pure joy, creating something new and useful, which works just like you designed it.
